# FranchiseOS design
Build the web-app design approved in conversation. Browser-local workspace, no login or paid API. Accept exact XLSX including incomplete rows, preserve originals, confirm cleaning, deterministic score with 60/10/30 weights, frozen tier percentile benchmarks (minimum 5 valid observations with variation; fallback whole upload), equal-value midpoint percentiles, unknown score ranges, no invented business evidence. Ground 2, confirmed first floor 1, Upper/Mall unresolved until edited. Gate recommendations on data completeness and known site; occupied pins and territory slots enforced. Allocation is provisional until onboarding verification. Plain-language guided parser explains application decisions and proposes supported updates for confirmation; visibly describe limits. No external LLM dependency. Configurable investment/area/launch minimums default off, disclosed. Import examples only after explicit checkbox. Persist locally, export/import JSON, CSV export, task completion. Public deployment for no-login judge access. Source workbook contains no real applicant dataset; demo must be clearly synthetic.
